## 0. 报告口径说明

- Token Plan 的**周限额**视套餐档位而定:无限档(如 Plus 档)周使用量不会被窗口限制
  - 若你的周限额是无限档,「周用量 diff」没有意义,本报告以 **5h 窗口**为主维度

- API 返回的 `current_interval_*` = **5h 窗口**;该窗口按**模型分类**独立计时

- API 模型分类命名 vs 控制台:
  - `general` → 通用文本/编程模型汇总
